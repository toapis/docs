---

- 統一視頻生成接口
- GrokVideo 渠道類型
- 異步任務模式，返回任務 ID
- 支持文生視頻和圖生視頻

## Authorizations

<ParamField header="Authorization" type="string" required>
  所有接口均使用 Bearer Token 認證

  獲取 API Key：訪問 [API Key 管理頁面](https://toapis.com/console/token)

  請求頭示例：
  ```
  Authorization: Bearer YOUR_API_KEY
  ```
</ParamField>

## Body

<ParamField body="model" type="string" default="grok-imagine-1.0-video" required>
  模型名稱，固定使用：
  - `grok-imagine-1.0-video`
</ParamField>

<ParamField body="prompt" type="string" required>
  視頻內容描述，支持多語言
</ParamField>

<ParamField body="aspect_ratio" type="string" default="16:9">
  視頻比例

  支持的格式：
  - `16:9` - 橫屏（默認）
  - `9:16` - 豎屏
  - `1:1` - 方形
  - `3:2` - 橫版
  - `2:3` - 豎版
</ParamField>

<ParamField body="duration" type="integer" default={6}>
  視頻時長（秒）

  取值範圍：6-30（最短 6 秒，最長 30 秒）

  ⚠️ 注意：必須輸入純數字（如 `6`），不要加引號，否則會報錯
</ParamField>

<ParamField body="quality" type="string" default="480p">
  視頻質量

  支持的值：
  - `480p`（默認）
  - `720p`
</ParamField>

<ParamField body="image_urls" type="string[]">
  參考圖 URL 數組（用於圖生視頻）

  限制：
  - 最多 7 張
  - 僅支持公網 URL
  - 不支持 base64
</ParamField>

## Response

<ResponseField name="id" type="string">
  任務唯一 ID
</ResponseField>

<ResponseField name="object" type="string">
  固定爲 `generation.task`
</ResponseField>

<ResponseField name="status" type="string">
  任務狀態：`queued` / `in_progress` / `completed` / `failed`
</ResponseField>

<RequestExample>
```bash cURL（文生視頻）
curl --request POST \
  --url https://toapis.com/v1/videos/generations \
  --header 'Authorization: Bearer <token>' \
  --header 'Content-Type: application/json' \
  --data '{
    "model": "grok-imagine-1.0-video",
    "prompt": "一隻狗在海邊奔跑，陽光明媚，慢動作鏡頭",
    "aspect_ratio": "16:9",
    "duration": 6,
    "quality": "720p"
  }'
```

```python Python
import requests

response = requests.post(
    "https://toapis.com/v1/videos/generations",
    headers={
        "Authorization": "Bearer your-ToAPIs-key",
        "Content-Type": "application/json",
    },
    json={
        "model": "grok-imagine-1.0-video",
        "prompt": "一隻狗在海邊奔跑，陽光明媚，慢動作鏡頭",
        "aspect_ratio": "16:9",
        "duration": 6,
        "quality": "720p",
    },
)

print(response.status_code)
print(response.json())
```

```javascript JavaScript

```
