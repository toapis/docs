平臺提供兩種 API 調用方式，通過 `model` 參數切換模型：

| API 格式 | 端點 | 說明 |
|----------|------|------|
| **Chat Completions**（默認） | `POST /v1/chat/completions` | 經典對話接口，兼容所有 OpenAI SDK，[查看文檔](./chat) |
| **Responses**（新） | `POST /v1/responses` | OpenAI 新一代 Agentic API，支持函數調用、內置工具、服務端多輪上下文，[查看文檔](./responses) |

<Tip>
標註 <code>Responses Only</code> 的模型僅支持 Responses API，不支持 Chat Completions。其餘模型默認通過 Chat Completions 調用。
</Tip>
