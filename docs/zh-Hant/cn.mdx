## [​](#sdk-與代碼示例)SDK 與代碼示例

官方 SDK 支持 Python、Node.js 和 Java。所有 SDK 均 OpenAI 兼容，僅需更改 Base URL 配置即可無縫遷移。
### [​](#python-sdk)Python SDK

通過 `pip install openai` 安裝。設置 Base URL 並使用現有 OpenAI 代碼，無需修改。
複製
```shiki
from openai import OpenAI
client = OpenAI(
    base_url="https://toapis.com/v1",
    api_key="your-ToAPIs-key"
)

```
### [​](#node-js-sdk)Node.js SDK

通過 `npm install openai` 安裝。配置 baseURL 參數爲 ToAPIs 端點，保留現有集成。
複製
```shiki
import OpenAI from 'openai';
const client = new OpenAI({
  baseURL: 'https://toapis.com/v1',
  apiKey: 'your-ToAPIs-key'
});

```
### [​](#java-sdk)Java SDK

OpenAI 兼容的 Java 客戶端。簡單配置更改即可訪問所有 ToAPIs 模型和供應商。
## [​](#從-openai-遷移)從 OpenAI 遷移

5 分鐘內切換到 ToAPIs。無需重寫代碼——只需更改 Base URL 和 API Key。
1

獲取 API Key

註冊 ToAPIs 並從[控制檯](https://toapis.com/console/token)獲取 API Key。2

更新 Base URL

將 OpenAI Base URL 改爲 ToAPIs 端點。現有 SDK 集成無需修改即可工作。3

測試端點

使用新的 Base URL 運行現有代碼。所有 OpenAI 兼容端點響應格式完全相同。在控制檯查看延遲和速率限制。

## [​](#常見問題)常見問題

如何從 OpenAI 遷移？

只需將 Base URL 更改爲 `https://toapis.com/v1` 並使用您的 ToAPIs API Key。保留現有 SDK——無需重寫代碼。遷移通常在 5 分鐘內完成。

SLA 包含什麼？

我們的企業 SLA 包括 99.9% 可用性保證、全球 CDN 加速、多供應商路由自動故障轉移和實時狀態監控。包含速率限制管理和 Webhook 支持。

定價如何與 OpenAI 比較？

ToAPIs 提供透明的按 Token 定價，比官方供應商更實惠。按需付費無需訂閱，企業用量享受批量折扣，無隱藏費用。

延遲和性能如何？

通過全球 CDN 加速和智能多供應商路由保證低延遲。全球邊緣節點確保最優響應時間。實時狀態監控讓您追蹤性能。[通用對話接口](./api-reference/chat/chat)
