## 準備工作

在開始之前，請確保：

1. **已安裝 OpenClaw**

   下載並安裝 OpenClaw，安裝完成後可在終端中運行 `openclaw` 命令

2. **已獲取 ToAPIs API 密鑰**

   登錄 [ToAPIs 控制檯](https://toapis.com/console/token) 獲取您的 API 密鑰（以 `sk-` 開頭）

**提示：** 如果還沒有 ToAPIs 賬戶，請先在 [ToAPIs](https://toapis.com) 註冊並獲取 API 密鑰。

## 配置步驟

在終端中運行以下命令啓動初始化嚮導：

```bash
openclaw onboard
```

按照提示依次填寫以下信息：

### 第一步：選擇模型/認證提供商

```
Model/auth provider:
```

使用**方向鍵**選擇 **Custom Provider**，然後按回車確認。

### 第二步：填寫 API Base URL

```
API Base URL:
```

輸入以下地址：

```
https://toapis.com/v1
```

### 第三步：填寫 API Key

```
API Key:
```

粘貼您從 [ToAPIs 控制檯](https://toapis.com/console/token) 獲取的 API 密鑰（`sk-xxxxxxxxxxxx`）。

### 第四步：選擇端點兼容性

```
Endpoint compatibility:
```

使用**方向鍵**選擇 **OpenAI-compatible**，然後按回車確認。

### 第五步：填寫模型 ID

```
Model ID:
```

輸入您要使用的模型 ID，例如：

```
claude-sonnet-4-6
```

## 配置完成

完成以上步驟後，OpenClaw 將使用 ToAPIs 作爲後端服務。您可以直接開始使用 AI 對話功能，所有請求將通過 ToAPIs 路由到對應的模型。

## 常見問題

### 認證失敗？

- 確認 API Key 正確且以 `sk-` 開頭
- 在 [ToAPIs 控制檯](https://toapis.com/console/token) 檢查密鑰是否有效
- 確保賬戶餘額充足

### 模型不可用？

- 確認 API Base URL 填寫爲 `https://toapis.com/v1`（包含 `/v1` 後綴）
- 確認 Endpoint compatibility 選擇了 **OpenAI-compatible**
- 檢查模型 ID 是否拼寫正確
