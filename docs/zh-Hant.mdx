## SDK 與代碼示例

Python、Node.js 和 Java 官方 SDK。所有 SDK 與 OpenAI 兼容，只需更改 Base URL 配置即可無縫遷移。

### Python SDK

使用 `pip install openai` 安裝。設置 Base URL 並使用現有 OpenAI 代碼，無需更改。

```python
from openai import OpenAI
client = OpenAI(
    base_url="https://toapis.com/v1",
    api_key="your-ToAPIs-key"
)
```

### Node.js SDK

使用 `npm install openai` 安裝。將 baseURL 參數配置爲 ToAPIs 端點，保持現有集成。

```javascript
import OpenAI from 'openai';
const client = new OpenAI({
  baseURL: 'https://toapis.com/v1',
  apiKey: 'your-ToAPIs-key'
});
```

### Java SDK

OpenAI 兼容的 Java 客戶端。簡單的配置更改即可訪問所有 ToAPIs 模型和供應商。

## 統一端點支持的模型

通過一個 OpenAI 兼容網關訪問領先的 LLM 供應商。所有模型均以一致的請求/響應格式提供。

### 聊天補全模型

用於聊天、補全和代碼任務的領先語言模型：

- **GPT-5**：OpenAI 旗艦模型，增強推理能力
- **GPT-4o 和 GPT-4o Mini**：平衡性能和成本的多模態模型
- **Claude Sonnet 4.5 和 Haiku 4.5**：Anthropic 複雜推理模型
- **Gemini 2.0 Flash 和 Flash Thinking**：Google 多模態模型

### 圖像生成模型

從文本提示生成圖像：

- **GPT-4o Image**：OpenAI 圖像生成模型
- **Gemini 2.5 Flash Image**：Google 高效圖像模型

### 視頻生成模型

視頻生成，支持異步任務跟蹤和 Webhook 回調：

- **OpenAI Sora2**：OpenAI 視頻生成模型
- **Google VEO3**：Google 視頻生成模型

### 語音模型

通過 OpenAI 兼容端點實現語音轉文本和文本轉語音：

- **Whisper-1**：OpenAI 轉錄模型
- **TTS**：多種聲音的文本轉語音
