- OpenAI-compatible Chat Completions API
- Select the `qwen3.5-plus` model via the `model` parameter
- Supports streaming output (SSE)
- Supports multi-turn conversation and system prompts
- Ultra-long context window supporting up to 256K input tokens
- Supports vision input (image understanding) via image URL or Base64 data


## Authorizations

<ParamField header="Authorization" type="string" required>
  All endpoints require Bearer Token authentication

  Get your API Key from the [API Key Management Page](https://toapis.com/console/token)

  Add to request header:
  ```
  Authorization: Bearer YOUR_API_KEY
  ```
</ParamField>

## Body

<ParamField body="model" type="string" default="qwen3.5-plus" required>
  Model name

  Example: `"qwen3.5-plus"`
</ParamField>

<ParamField body="messages" type="object[]" required>
  List of messages comprising the conversation, ordered chronologically

  <Expandable title="messages[n]">
    <ParamField body="role" type="string" required>
      Role of the message author: `system`, `user`, or `assistant`
    </ParamField>
    <ParamField body="content" type="string | array" required>
      Message content — string or array of content blocks. For vision input, pass an array containing `text` and `image_url` content blocks
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="stream" type="boolean" default={false}>
  Whether to stream the response (Server-Sent Events)

  - `true`: Stream tokens incrementally as they are generated
  - `false`: Return the complete response at once
</ParamField>

<ParamField body="max_tokens" type="integer">
  Maximum number of tokens to generate

  Uses the model's default maximum when not specified
</ParamField>

<ParamField body="temperature" type="number" default={1}>
  Sampling temperature controlling output randomness

  - Range: `0` ~ `2`
  - Lower values produce more deterministic output; higher values produce more random output
</ParamField>

<ParamField body="top_p" type="number" default={1}>
  Nucleus sampling probability threshold

  Range: `0` ~ `1`. Avoid modifying both `temperature` and `top_p` simultaneously
</ParamField>

<ParamField body="stop" type="string | string[]">
  Stop sequences — generation halts when any of these strings are encountered

  Up to 4 stop sequences
</ParamField>

## Response

<ResponseField name="id" type="string">
  Unique identifier for the completion request
</ResponseField>

<ResponseField name="object" type="string">
  Object type, always `chat.completion`
</ResponseField>

<ResponseField name="created" type="integer">
  Unix timestamp of when the request was created
</ResponseField>

<ResponseField name="model" type="string">
  The model that was actually used
</ResponseField>

<ResponseField name="choices" type="object[]">
  List of generated completions

  - `choices[].message.role`: Role of the response, always `assistant`
  - `choices[].message.content`: Generated text content
  - `choices[].finish_reason`: Stop reason — `stop` / `length` / `content_filter`
  - `choices[].index`: Index of this choice
</ResponseField>

<ResponseField name="usage" type="object">
  Token usage statistics for the request

  - `usage.prompt_tokens`: Number of input tokens
  - `usage.completion_tokens`: Number of output tokens
  - `usage.total_tokens`: Total tokens consumed
</ResponseField>

```python Python (openai SDK)
from openai import OpenAI

client = OpenAI(
    api_key="your-ToAPIs-key",
    base_url="https://toapis.com/v1"
)

response = client.chat.completions.create(
    model="qwen3.5-plus",
    messages=[
        {"role": "user", "content": "Write an outline for a product requirements document"}
    ]
)

print(response.choices[0].message.content)
```

```python Python (Streaming)
from openai import OpenAI

client = OpenAI(
    api_key="your-ToAPIs-key",
    base_url="https://toapis.com/v1"
)

stream = client.chat.completions.create(
    model="qwen3.5-plus",
    messages=[
        {"role": "system", "content": "You are an experienced product manager"},
        {"role": "user", "content": "Write an outline for a product requirements document"}
    ],
    stream=True
)

for chunk in stream:
    if chunk.choices[0].delta.content:
        print(chunk.choices[0].delta.content, end="", flush=True)
```

```javascript JavaScript (openai SDK)

const client = new OpenAI({

console.log(response.choices[0].message.content);
```
