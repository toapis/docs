Платформа предоставляет два формата API. Используйте параметр `model` для выбора модели:

| Формат API | Эндпоинт | Описание |
|----------|------|------|
| **Chat Completions** (по умолчанию) | `POST /v1/chat/completions` | Классический chat API, совместимый с OpenAI SDK. [Документация](./chat) |
| **Responses** (новый) | `POST /v1/responses` | Новый agentic API OpenAI с function calling, встроенными инструментами и серверным многоходовым контекстом. [Документация](./responses) |

<Tip>
Модели с пометкой <code>Responses Only</code> поддерживают только Responses API и не поддерживают Chat Completions. Остальные модели по умолчанию вызываются через Chat Completions.
</Tip>
