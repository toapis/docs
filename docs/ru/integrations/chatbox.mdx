## Подготовка

Перед началом убедитесь:

1. **ChatBox установлен**
   
   Скачайте с [ChatBox GitHub](https://github.com/Bin-Huang/chatbox) или [ChatBox Website](https://chatboxai.app/)

2. **API ключ ToAPIs получен**
   
   Войдите в [консоль ToAPIs](https://toapis.com/console/token) и получите ваш API ключ (начинается с `sk-`)

## Шаг 1: Запустите ChatBox

1. Запустите приложение ChatBox
2. Нажмите **"Использовать свой API Key"**
3. Или откройте **⚙️ Настройки**

## Шаг 2: Настройте ToAPIs API

### Выберите провайдера

В настройках выберите:
- **OpenAI API** (для моделей GPT)
- **Claude API** (для моделей Claude)
- **Gemini API** (для моделей Gemini)

### Заполните данные

| Параметр | Значение |
| --- | --- |
| **API Key** | Ваш ToAPIs API ключ (`sk-xxxx`) |
| **API Host** | `https://toapis.com` |

## Шаг 3: Выберите модель

Рекомендуемые модели:

| Модель | ID | Особенности |
| --- | --- | --- |
| GPT-5 | `gpt-5` | Самая мощная модель |
| GPT-4o | `gpt-4o` | Высокое качество |
| Claude Sonnet 4.5 | `claude-sonnet-4-5-20250929` | Код и рассуждения |

## Шаг 4: Начните использование

1. Вернитесь на главный экран
2. Введите ваш вопрос
3. Нажмите отправить
