## Подготовка

Перед началом убедитесь, что у вас есть:

1. **Установленный OpenClaw**

   Скачайте и установите OpenClaw. После установки команда `openclaw` должна быть доступна в терминале.

2. **API-ключ ToAPIs**

   Войдите в [консоль ToAPIs](https://toapis.com/console/token) для получения API-ключа (начинается с `sk-`).

**Примечание:** Если у вас ещё нет аккаунта ToAPIs, сначала зарегистрируйтесь на [ToAPIs](https://toapis.com).

## Шаги настройки

Запустите следующую команду в терминале для запуска мастера настройки:

```bash
openclaw onboard
```

Следуйте подсказкам и заполните информацию ниже:

### Шаг 1: Выбор провайдера модели/авторизации

```
Model/auth provider:
```

Используйте **клавиши со стрелками** для выбора **Custom Provider**, затем нажмите Enter для подтверждения.

### Шаг 2: Ввод базового URL API

```
API Base URL:
```

Введите следующий URL:

```
https://toapis.com/v1
```

### Шаг 3: Ввод API-ключа

```
API Key:
```

Вставьте ваш API-ключ ToAPIs, полученный в [консоли ToAPIs](https://toapis.com/console/token) (`sk-xxxxxxxxxxxx`).

### Шаг 4: Выбор совместимости эндпоинта

```
Endpoint compatibility:
```

Используйте **клавиши со стрелками** для выбора **OpenAI-compatible**, затем нажмите Enter для подтверждения.

### Шаг 5: Ввод ID модели

```
Model ID:
```

Введите ID модели, которую хотите использовать, например:

```
claude-sonnet-4-6
```

## Готово

После завершения настройки OpenClaw будет использовать ToAPIs в качестве бэкенда. Все ваши запросы будут маршрутизированы через ToAPIs к выбранной модели.

## Устранение неполадок

### Ошибка аутентификации?

- Убедитесь, что API-ключ корректен и начинается с `sk-`
- Проверьте активность ключа в [консоли ToAPIs](https://toapis.com/console/token)
- Убедитесь, что на вашем счету достаточно средств

### Модель недоступна?

- Убедитесь, что API Base URL задан как `https://toapis.com/v1` (включая суффикс `/v1`)
- Убедитесь, что Endpoint compatibility установлен как **OpenAI-compatible**
- Проверьте правильность написания ID модели
