## Что потребуется

1. Создайте **API-ключ ToAPIs** в [консоли ToAPIs](https://toapis.com/console/token).
2. Установите Codex CLI по [официальной документации](https://developers.openai.com/codex/cli) или командой:

   ```bash
   npm install -g @openai/codex
   ```

3. Установите CC Switch только с [официального сайта](https://ccswitch.io) или из [официальных GitHub Releases](https://github.com/farion1231/cc-switch/releases).

## Добавьте ToAPIs в CC Switch

1. Откройте CC Switch и выберите **Codex** в переключателе приложений.
2. Нажмите **+** и выберите **провайдер для приложения**.
3. Выберите пресет **Custom** и заполните поля:

| Поле | Значение |
| --- | --- |
| Имя | `ToAPIs` |
| API Key | Ваш API-ключ ToAPIs |
| API endpoint / Base URL | `https://toapis.com/v1` |
| Модель | `gpt-5.3-codex` |
| Протокол API | `Responses` |
| Локальный роутинг / сопоставление моделей | **Выключено** |

4. Нажмите **Добавить**, затем **Включить** на карточке ToAPIs.
5. Полностью закройте Codex и терминал, затем откройте терминал заново.

<Note>
ToAPIs нативно поддерживает `POST /v1/responses`. Не включайте локальный роутинг: он нужен провайдерам, которые поддерживают только Chat Completions.
</Note>

## Запуск и проверка

```bash
codex
```

Отправьте простую задачу:

```text
Проверь текущий проект и опиши структуру основных каталогов.
```

Если Codex отвечает нормально, подключение завершено.

## Смена модели

CC Switch может получить доступные модели через `/v1/models`. Идентификаторы также перечислены на странице [моделей ToAPIs](../api-reference/chat/models).

Для большинства задач используйте `gpt-5.3-codex`, для более быстрых ответов — `gpt-5.3-codex-spark`, а `gpt-5.3-codex-official` выбирайте только когда нужен официальный прямой канал. Приоритет имеет список `/v1/models`, полученный CC Switch.

## Решение проблем

- **Используется старый провайдер**: полностью перезапустите Codex и терминал.
- **`401 Unauthorized`**: проверьте ключ, его статус и баланс аккаунта.
- **`404` или неверный путь Responses**: проверьте Base URL, протокол `Responses` и выключенный локальный роутинг.
- **Модель недоступна**: запросите `/v1/models` с тем же ключом.

CC Switch управляет файлами `~/.codex/auth.json` и `~/.codex/config.toml`. Не добавляйте эти файлы или API-ключи в Git.

Дополнительные инструкции находятся в [официальном руководстве CC Switch](https://github.com/farion1231/cc-switch/tree/main/docs/user-manual/en).
