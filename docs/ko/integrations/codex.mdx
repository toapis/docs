## 준비 사항

1. [ToAPIs Console](https://toapis.com/console/token)에서 **ToAPIs API 키**를 생성합니다.
2. [Codex 공식 문서](https://developers.openai.com/codex/cli)를 따라 Codex CLI를 설치하거나 다음 명령을 실행합니다.

   ```bash
   npm install -g @openai/codex
   ```

3. [CC Switch 공식 사이트](https://ccswitch.io) 또는 [공식 GitHub Releases](https://github.com/farion1231/cc-switch/releases)에서 CC Switch를 설치합니다.

## CC Switch에 ToAPIs 추가

1. CC Switch를 열고 앱 전환기에서 **Codex**를 선택합니다.
2. 오른쪽 위 **+**를 클릭하고 **앱 전용 공급자**를 선택합니다.
3. **Custom** 프리셋을 선택하고 다음 값을 입력합니다.

| 항목 | 값 |
| --- | --- |
| 이름 | `ToAPIs` |
| API Key | ToAPIs API 키 |
| API endpoint / Base URL | `https://toapis.com/v1` |
| 모델 | `gpt-5.3-codex` |
| API 프로토콜 | `Responses` |
| 로컬 라우팅/모델 매핑 | **끔** |

4. **추가**를 클릭한 뒤 ToAPIs 공급자 카드에서 **활성화**를 클릭합니다.
5. 실행 중인 Codex와 터미널을 종료하고 터미널을 다시 엽니다.

<Note>
ToAPIs는 `POST /v1/responses`를 기본 지원합니다. Chat Completions 전용 공급자에 사용하는 로컬 라우팅/모델 매핑은 켜지 마세요.
</Note>

## 실행 및 확인

```bash
codex
```

간단한 작업을 입력합니다.

```text
현재 프로젝트를 확인하고 주요 디렉터리 구조를 설명해 주세요.
```

정상적으로 응답하면 설정이 완료된 것입니다.

## 모델 변경

CC Switch의 모델 가져오기 버튼으로 `/v1/models`에서 사용 가능한 모델을 확인할 수 있습니다. [ToAPIs 모델 목록](../api-reference/chat/models)에서도 모델 ID를 확인할 수 있습니다.

일반적인 코드 작업에는 `gpt-5.3-codex`, 속도 우선 작업에는 `gpt-5.3-codex-spark`, 공식 직결 채널이 필요한 경우에는 `gpt-5.3-codex-official`을 선택하세요. 실제 사용 가능 모델은 CC Switch가 `/v1/models`에서 가져온 목록을 우선합니다.

## 문제 해결

- **이전 공급자가 계속 사용됨**: Codex와 터미널을 완전히 종료한 후 다시 실행합니다.
- **`401 Unauthorized`**: API 키, 키 상태, 계정 잔액을 확인합니다.
- **`404` 또는 Responses 경로 오류**: Base URL, `Responses` 프로토콜, 로컬 라우팅이 꺼져 있는지 확인합니다.
- **모델 사용 불가**: 같은 키로 `/v1/models`를 조회합니다.

CC Switch는 `~/.codex/auth.json`과 `~/.codex/config.toml`을 관리합니다. 이 파일이나 API 키를 Git에 커밋하지 마세요.

자세한 내용은 [CC Switch 공식 사용자 매뉴얼](https://github.com/farion1231/cc-switch/tree/main/docs/user-manual/en)을 참고하세요.
