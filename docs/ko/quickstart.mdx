# 빠른 시작

ToAPIs는 OpenAI 호환 텍스트 API와 통합 비동기 이미지·비디오 생성 API를 제공합니다. 이 가이드에서는 현재 사용 가능한 모델로 첫 요청을 전송합니다.

## 1단계: API 키 받기

1. [API Key Management](https://toapis.com/console/token) 페이지를 엽니다
2. 로그인하고 새 API 키를 생성합니다
3. 키는 한 번만 표시되므로 안전하게 저장합니다

## 2단계: 모델 선택

| 유형 | 권장 시작 모델 | 설명 |
| --- | --- | --- |
| 텍스트 | `gpt-5.6-terra` | 채팅과 Agent 워크플로에 적합한 균형형 모델 |
| 이미지 | `gpt-image-2` | 텍스트 및 참조 이미지 생성 지원 |
| 비디오 | `sora-2-vvip` | 텍스트, 이미지, 캐릭터 참조 기반 비디오 생성 |

사용 가능 모델은 [모델 목록 API](./api-reference/chat/list-models)와 각 모델 문서를 확인하세요.

## 3단계: 요청 보내기

### 텍스트 생성

```bash
curl --request POST \
  --url https://toapis.com/v1/chat/completions \
  --header "Authorization: Bearer YOUR_API_KEY" \
  --header "Content-Type: application/json" \
  --data '{
    "model": "gpt-5.6-terra",
    "messages": [
      {"role": "user", "content": "자기소개를 해 주세요"}
    ]
  }'
```

### 이미지 생성

```bash
curl --request POST \
  --url https://toapis.com/v1/images/generations \
  --header "Authorization: Bearer YOUR_API_KEY" \
  --header "Content-Type: application/json" \
  --data '{
    "model": "gpt-image-2",
    "prompt": "영화 같은 조명을 받은 귀여운 판다",
    "size": "1:1",
    "resolution": "1k",
    "n": 1
  }'
```

### 비디오 생성

```bash
curl --request POST \
  --url https://toapis.com/v1/videos/generations \
  --header "Authorization: Bearer YOUR_API_KEY" \
  --header "Content-Type: application/json" \
  --data '{
    "model": "sora-2-vvip",
    "prompt": "해안에 부딪히는 파도, 영화 같은 카메라 움직임",
    "duration": 12,
    "aspect_ratio": "16:9"
  }'
```

## 4단계: 비동기 작업 확인

텍스트 요청은 결과를 바로 반환합니다. 이미지와 비디오는 작업 ID를 반환하므로 유형에 맞는 엔드포인트를 사용하세요.

```bash
# 이미지 작업
curl https://toapis.com/v1/images/generations/YOUR_TASK_ID \
  -H "Authorization: Bearer YOUR_API_KEY"

# 비디오 작업
curl https://toapis.com/v1/videos/generations/YOUR_TASK_ID \
  -H "Authorization: Bearer YOUR_API_KEY"
```

## Task Webhook 설정

Token에 HTTPS URL과 서명 secret을 설정하고 필요하면 동일 origin `callback_url`을 전송합니다. raw body와 `X-ToAPIs-Webhook-*`을 HMAC-SHA256으로 검증하고 event ID를 멱등 처리하세요. 조회는 대체 경로이며 `429`에서는 `Retry-After`를 따릅니다. [Webhook](/docs/ko/api-reference/webhooks/task-webhooks).
