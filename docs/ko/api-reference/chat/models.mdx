The platform provides two API formats. Use the `model` parameter to switch models:

| API Format | 엔드포인트 | 설명 |
|----------|------|------|
| **Chat Completions** (default) | `POST /v1/chat/completions` | Classic chat API, compatible with OpenAI SDKs. [View docs](./chat) |
| **응답s** (new) | `POST /v1/responses` | Newer OpenAI agentic API with function calling, built-in tools, and server-side multi-turn context. [View docs](./responses) |

<Tip>
모델 marked as <code>응답s Only</code> only support the 응답s API and do not support Chat Completions. Other models are called through Chat Completions by default.
</Tip>
