---
title: "비동기 작업 속도 제한"
description: "ToAPIs 제출 및 조회 제한"
---

ToAPIs는 비동기 제출과 상태 조회에 독립 token bucket을 사용하며 동기 모델 요청 한도를 소비하지 않습니다.

| 그룹 | 제출 RPM / RPS / 10초 버스트 | 조회 RPM / RPS / 10초 버스트 |
| --- | --- | --- |
| `default` | 300 / 5 / 50 | 3,000 / 50 / 500 |
| `vip` | 1,000 / 16.7 / 167 | 10,000 / 166.7 / 1,667 |
| `svip` | 2,000 / 33.3 / 334 | 30,000 / 500 / 5,000 |

사용자 ID 기준이며 같은 사용자의 모든 Token이 공유합니다. 제출/조회 버킷은 독립적이고 비즈니스 실패는 계산되며 `429`는 계산되지 않습니다. 배치 조회는 요청 1회로 계산되며 최대 100개입니다.

```text
Retry-After
X-RateLimit-Limit
X-RateLimit-Remaining
X-RateLimit-Reset
X-RateLimit-Category: async_submit | async_query
```

```json 429
{"error":{"code":"rate_limit_exceeded","message":"Async task request rate exceeded"}}
```

```json 503
{"error":{"code":"rate_limit_unavailable","message":"The async task submit limiter is temporarily unavailable"}}
```

제출 제한 장애는 `503`, 조회는 허용됩니다. [Webhook](/docs/ko/api-reference/webhooks/task-webhooks)을 기본으로 사용하고 폴링은 5~10초 이상 간격과 무작위 지터를 적용하세요. `429/503`에서는 `Retry-After`를 우선하고 없으면 지수 백오프를 사용합니다.
